# UI-автотесты на Selenide

Проект содержит автоматизированные UI-тесты для проверки пользовательских сценариев (авторизация, работа с каталогом и корзиной).

В качестве тестового стенда используется `saucedemo.com`.

* Java 21
* Selenide 7.2.2
* JUnit 5
* Gradle

## Архитектура

Проект реализован с использованием паттерна **Page Object** и принципов инкапсуляции:
* Локаторы и действия со страницами скрыты внутри классов в пакете `pages`.
* Повторяющиеся блоки интерфейса вынесены в отдельные компоненты.

### Структура проекта

```text
src/test/java/org/example/tests/
├── BaseTest.java          # Базовая настройка Selenide и очистка состояния
├── ScenariosTest.java     # Основные тест-кейсы
├── components/
│   └── ProductCard.java   # Компонент карточки товара
└── pages/
    ├── LoginPage.java     # Страница авторизации
    ├── InventoryPage.java # Каталог товаров
    └── CartPage.java      # Корзина
```

## Реализованные тест-кейсы

* Успешная авторизация и добавление товара в корзину.
* Попытка авторизации с неверным паролем (проверка текста ошибки).
* Проверка входа под заблокированным пользователем.
* Добавление нескольких товаров и проверка счетчика корзины.
